# Bundled fonts

These OFL-licensed variable fonts are packaged with Still so preview and export
use the same glyph data:

- Noto Sans SC
- Noto Sans Arabic
- Noto Sans Devanagari
- Noto Serif SC
- Inter
- Playfair Display
- Noto Emoji

The font binaries are distributed under the SIL Open Font License 1.1. See
`OFL.txt`.

`NotoSansArabic-Variable.ttf` is the Noto Sans Arabic variable font from the
[Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/notosansarabic).

`NotoSansDevanagari-Variable.ttf` is the Noto Sans Devanagari variable font
from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/notosansdevanagari).
